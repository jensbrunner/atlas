# API (M1)

Base path: `/api/v1` (health is at `/healthz`). OpenAPI is generated by FastAPI
at `/docs` and `/openapi.json`.

## `GET /healthz`

Performs no paid model calls. Checks `SELECT 1` and the Alembic schema version.

```json
{
  "status": "ok",
  "version": "0.1.0",
  "mode": "offline_test",
  "database": "ok",
  "schema_version": "467150db4c93"
}
```

Returns `503` with `status: "degraded"` when the database cannot be opened or
the `alembic_version` table is absent (unmigrated database).

## `POST /api/v1/campaigns`

Creates and seeds a new **The Broken Span** campaign. No model is called.

Request (both fields optional):

```json
{
  "title": "The Broken Span",
  "seed": 20261111
}
```

Response `201`:

```json
{
  "id": "cmp_01J...",
  "title": "The Broken Span",
  "rules_version": "0.1",
  "status": "active",
  "state_version": 0,
  "current_time": 0,
  "seed": 20261111,
  "created_at": "2026-11-11T00:00:00Z"
}
```

## `GET /api/v1/campaigns`

Returns `{ "campaigns": [ ... ] }`, newest first.

## `GET /api/v1/campaigns/{campaign_id}`

Returns one campaign summary or `404`.

## `POST /api/v1/campaigns/{campaign_id}/turns`

Submits one player action. The deterministic M1 parser supports explicit
travel, observation, search, speech, and wait text, for example:

- `look around`, `survey the square`
- `go to north quarry`, `walk to the old bridge`
- `search the quarry`, `look for supplies`
- `talk to the magistrate`, `ask vessa`
- `wait 15 minutes`, `rest 2 hours`

Request:

```json
{
  "client_action_id": "614b9f3a-d3e0-4d60-b902-a414bc358a9f",
  "player_text": "search the square",
  "expected_version": 0
}
```

`client_action_id` must be a UUID and is the idempotency key. Repeating it
returns the stored turn, even while or after the original request completes.
`expected_version` is optional; when supplied and stale, the request returns a
typed `409 version_conflict` without creating a turn.

## `GET /api/v1/campaigns/{campaign_id}/turns`

Query parameters:

- `after` — return turns with ordinal greater than this value (default `0`).
- `limit` — page size, 1–200 (default `50`).

Returns `{ "turns": [ ... ], "next_cursor": 12 }`. Only committed turns are
listed; `next_cursor` is the last ordinal when the page is full, otherwise
`null`.

## `GET /api/v1/campaigns/{campaign_id}/turns/{turn_id}`

Returns one turn in the same shape as the POST response, or `404`. A durable
failed turn can be inspected through this route.

## `GET /api/v1/campaigns/{campaign_id}/state`

Returns a player-safe projection, current version, focused scene, public
entities, and up to 20 recent observations.

```json
{
  "campaign_id": "cmp_01J...",
  "current_time": 60,
  "state_version": 1,
  "scene": {
    "actor": {"id": "ent_01J...", "kind": "player_character", "slug": "rowan", "display_name": "Rowan", "state": {"location_id": "ent_01J...", "health": 7, "stress": 1, "supplies": 1, "currency": 12}},
    "location": {"id": "ent_01J...", "kind": "location", "slug": "town_square", "display_name": "Market Square", "state": {}},
    "present": [
      {"id": "ent_01J...", "kind": "npc", "slug": "magistrate_elin", "display_name": "Magistrate Elin", "state": {"location_id": "ent_01J...", "health": 6, "stress": 2}}
    ]
  },
  "entities": [
    {"id": "ent_01J...", "kind": "player_character", "slug": "rowan", "display_name": "Rowan", "state": {"location_id": "ent_01J...", "health": 7, "stress": 1, "supplies": 1, "currency": 12}}
  ],
  "recent_observations": [ ... ]
}
```

Entity `static` data is not returned by this view. Entities and observations
marked GM-only are omitted entirely, including their IDs.

## `GET /api/v1/campaigns/{campaign_id}/journal`

Query parameters:

- `after_seq` — return observations with sequence greater than this value
  (default `0`).
- `limit` — page size, 1–200 (default `100`).

Returns `{ "entries": [ ... ], "next_cursor": 20 }`, where entries use the
observation shape shown above. GM-only observations, and observations that refer
to GM-only subjects, are filtered out.

## Error shape

Domain errors use a stable envelope:

```json
{
  "error": {
    "code": "not_found",
    "message": "campaign 'cmp_x' does not exist",
    "details": {"campaign_id": "cmp_x"}
  }
}
```

| HTTP | Codes |
|---|---|
| 404 | `not_found` |
| 409 | `version_conflict`, `turn_pending`, `turn_failed` |
| 422 | `invalid_turn_plan`, `unparsed_intent`, `narrator_invalid`, `invariant.*` |
| 400 | other domain failures |

Request-schema failures (for example a missing field or a `client_action_id`
outside 36 characters) use FastAPI's standard `422` validation response. A
36-character value that is not a UUID reaches the service and returns the domain
error shape with `invalid_turn_plan`.

Lifecycle semantics behind the errors:

- `unparsed_intent` — durable `FAILED` turn; state is unchanged.
- `narrator_invalid` — narration rejected before commit; durable `FAILED` turn;
  state is unchanged.
- `turn_failed` — the client id already points at a durable failed turn.
- `version_conflict` — expected or snapshot version is stale; no effects from
  that request are applied.
- `turn_pending` — a turn exists but has not committed; clients should retry the
  same client id.

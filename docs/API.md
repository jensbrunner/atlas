# API (M0)

Base path: `/api/v1` (health is at `/healthz`). OpenAPI is generated by FastAPI
at `/docs` and `/openapi.json`.

## `GET /healthz`

Performs no paid model calls. Checks `SELECT 1` and the Alembic schema version.

```json
{
  "status": "ok",
  "version": "0.1.0",
  "mode": "offline_test",
  "database": "ok",
  "schema_version": "c4b9a1b5dbf2"
}
```

Returns `503` with `status: "degraded"` when the database cannot be opened or
the `alembic_version` table is absent (unmigrated database).

## `POST /api/v1/campaigns`

Creates and seeds a new **The Broken Span** campaign. No model is called.

Request (both fields optional):

```json
{
  "title": "The Broken Span",
  "seed": 20261111
}
```

Response `201`:

```json
{
  "id": "cmp_01J...",
  "title": "The Broken Span",
  "rules_version": "0.1",
  "status": "active",
  "state_version": 0,
  "current_time": 0,
  "seed": 20261111,
  "created_at": "2026-11-11T00:00:00Z"
}
```

## `GET /api/v1/campaigns`

Returns `{ "campaigns": [ ... ] }`, newest first.

## `GET /api/v1/campaigns/{campaign_id}`

Returns one campaign summary or `404`.

## Error shape

Domain errors use a stable envelope:

```json
{
  "error": {
    "code": "not_found",
    "message": "campaign 'cmp_x' does not exist",
    "details": {"campaign_id": "cmp_x"}
  }
}
```

M0 codes include `not_found` (404), `version_conflict` (409), `turn_pending`
(409), `invalid_turn_plan` (422), `invariant.*` (422), and generic domain
failures (400).

## Not implemented yet (M1)

The following VISION.md endpoints are deliberately absent:

- `GET /campaigns/{id}/state`
- `GET /campaigns/{id}/turns?cursor=`
- `POST /campaigns/{id}/turns`
- `GET /campaigns/{id}/turns/{turn_id}`
- `GET /campaigns/{id}/journal`
- checkpoint/export/preferences routes

The M0 turn engine is exercised by `scripts/offline_turn.py` and integration
tests. It accepts explicit typed commands rather than a parsed player intent.
Player-facing endpoints must filter GM-only facts and must not expose raw roll
seeds before an authorized reveal.

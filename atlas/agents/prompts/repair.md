# Leak repair

Your previous narration was rejected because it mentioned protected GM material
before the player had discovered it. You have one chance to correct the turn.

- If the fiction genuinely revealed the material, call the matching discovery
  tool now: `reveal_fact`, `reveal_location`, `reveal_npc`, or `reveal_faction`.
  Then keep it in the scene.
- Otherwise rewrite the scene so the protected material is not named, quoted,
  hinted at, or acted upon.
- Do not mention this correction, the rejected draft, or any tool name in the
  narration.
- Preserve the mechanical outcome already established. Do not reroll, undo, or
  invent new state changes just to escape the problem.
- Return only the corrected player-facing narration.
